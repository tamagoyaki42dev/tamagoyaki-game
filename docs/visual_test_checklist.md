# 視覚確認チェックリスト

コミット前に Godot でゲームを起動し、以下を全て目視確認すること。

## 戦闘演出

- [ ] HPバーが右から左へ減る（左から減っていたら NG）
- [ ] ダメージを受けたユニットが赤くフラッシュする
- [ ] 補助→攻撃の演出が1秒ずつ順番に再生される（同時再生されていたら NG）
- [ ] 死亡ユニットが消える（scale=0 または傾き演出）
- [ ] ローテーション時に前列・中列・後列が正しく入れ替わる
- [ ] クリット時に金色の「Critical!」が拡大して上昇→フェードアウトする（ダメージ数字と重ならず視認できること）

## UI

- [ ] 右パネルにユニットの名前・HPが表示される
- [ ] 右パネル：各ユニット行の右端にキャラ画像スペース（プレースホルダー）が表示されること
- [ ] ターン数が正しくカウントアップされる
- [ ] 戦闘終了時に勝利/敗北が表示される

## 攻撃補助エフェクト

- [ ] 攻撃補助発動時：補助キャラ（中衛）にオレンジフラッシュ＋「ATK Up」テキストが浮上すること
- [ ] 攻撃補助発動時：前衛（攻撃側）にもオレンジフラッシュ（充電感）が入ること
- [ ] テキストスタイルがダメージ数字・回復数字と統一されていること

- [ ] デフォルトはステイ（何も押さず0でステイ確定・ステイボタンが明るい）

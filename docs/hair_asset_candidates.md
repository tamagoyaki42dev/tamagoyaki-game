# 髪アセット候補リスト（商用利用の観点で選別中）

女性キャラの3D髪を BOOTH から調達するための候補台帳。**このプロジェクトは itch/Steam で有料販売＝商用**なので、採用基準は「**商用利用が明記されている**もの」（silent は原則見送り。詳細は [CREDITS.md](../CREDITS.md) の運用ルール）。

**方針転換（2026-07-12）**：「髪」で検索すると尖った特殊髪型に偏るため、**「髪」をキーワードから外し、無料のオリジナル3Dアバター全般から探す**方式に変更。Blenderで髪だけ切り離せるようになった（体・顔ごと削除可能）ため、アバター丸ごとが髪の供給源になる。**FuwaOsageは採用決定済み**（詳細は [CREDITS.md](../CREDITS.md) 参照）。

検証ステータスの意味：
- ✅ **確認済み**：私が実際に商品ページを開き、商用利用OKの文言を確認した
- 📋 **選別済み・要現地確認**：第三者のまとめ記事が「商用可」として選別。ページ本文での最終確認は未実施（購入/DL前に各自確認）
- ⚠️ **商用未確認**：改変用髪型としては候補だが、商用可否は未確認（多くは silent = 商用NG側の可能性）

> **重要な傾向（2026-07-12 調査）**：VRChat向けの「髪だけ」ショップは**商用利用に触れていない（silent）ものが多数派**。実際に大手 QuQu は改変OK・再配布禁止のみで商用の明記なし＝うちの基準では不採用。**「髪だけ」を商用可で揃えるより、「商用可アバターから髪を抜く」ルートの方が確実**。
>
> **予算方針（2026-07-12 決定）**：このプロジェクトはKayKit同様、髪も**無料のみ**で揃える（有料は不採用）。「商用明記」に加え「silentだが常識的にOKと判断できる無料素材」も対象に含める（FelizHairと同水準の判断基準）。
>
> **無料×商用明記の母数は非常に薄いと判明**：VRChat向け3D髪ショップの大半（QuQu・ぽち屋・Anka・SpaceModelCreation等）は**有料（¥500〜¥2,500）**。商用条件を丁寧に明記するショップほど有料である傾向が強く、無料の中でも「Aurora Hair」のように**商用だけ別途有料**（非商用は無料、営利は+¥1,000）というパターンが多い。無料かつ商用も無条件で許可、まで揃う例は少数。

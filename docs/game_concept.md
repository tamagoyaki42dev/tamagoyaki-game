# ゲームコンセプト（背骨）

## 内側と外側の構造

- **内（不変）** = 世代継承＋騎兵隊運営。原作（モールモース/V&B）のコアを崩さない
- **外（可変）** = 滅亡→再興のローグライクループ。毎回異なる文脈で始まる

プレイヤーの時間投資（キャラへの愛着・形質の蓄積）は内側に残り続ける。
外側がリセットされても内側は引き継がれるため、負けが「終わり」ではなく「次世代への布石」になる。

## 設計の原則

この骨格を外さなければ、エンジニアリングとプロトタイピングは進めてよい。
「何が引き継がれ、何がリセットされるか」の**外側リセットの境界**（滅亡→再興で内側に残す物）は完成版スコープのため保留（プロトタイプを回しながら調整する）。

## ゲームループの全体像（2026-07-05 定義）

**内側ループ（＝継承育成／proto2スコープ）を機構として定義した。** 外側ループ（滅亡→再興のリセットと引き継ぎ）は完成版スコープのため保留。機構の詳細は `docs/proto2_design.md`。

### 始まり
澱みの中で新しい文明が目覚め、初期騎兵隊を得て始まる。

### 内側の日常（拠点 ⇄ 遠征）
- **時間は拠点⇔町の往復移動時間で刻む。** 町ごとに拠点からの距離を持ち、遠い町への遠征ほど多く時間が経つ。
- **隊員の増**：拠点での募集が基本（将来イベント枠もありうる）。
- **隊員の減**：加齢引退／戦闘死亡（味方1体でも倒れたら即撤退＝その1体は永久ロスト）。

### 継承（内側の蓄積＝「投資が形になる」の核）
- 隊内で親密度が育った2人が結婚・出産し、移動時間の積算で**15年後に子が入隊**する。
- 子は両親の**個体値を重み付き合成で継ぐ**ため、通常募集より強くなりうる。

### 終わり（ゲームオーバー）
- **文明HP＝町3つ。** 町は「防衛戦に負ける」か「一定時間放置される」と滅亡する。距離ゆえに全ての町を同時には守れず、どの町を諦めるかのトリアージが生まれる。
- 滅亡した町は、拠点との**導線が確保されていて＋一定時間経過で復活**する（普段は落ちても戻せる）。
- **3つの町が同時に滅亡するとゲームオーバー**（＝累積でなく同時全滅。復活があるから"同時"に意味が出る）。

### 勝利エンド
とりあえずの勝利エンドは置く。ただし続きがありそうな**煮え切らない終わり方**にする（滅亡→再興ループへの伏線）。

# SNS投稿ワークフロー

## コミット後（自動）

- Bluesky：`tools/post_update.py` が自動実行（git hook）
  - F12スクショがあれば画像付き、なければテキストのみ
  - X：APIが有料のため現在停止中

## 動画投稿時（週2ペース）

1. Snipping Toolでゲーム録画
2. Movaviで縦変換（1080×1920）してエクスポート
3. YouTube Shortsにアップロード
4. TikTokに同じ動画をアップロード
5. noteの下書きにネタがあれば記事にする（devlogの `## noteネタ` 参照）

## X 画像投稿（未解決）

- 選択肢A：Buffer無料プランで週まとめて予約投稿
- 選択肢B：手動で都度投稿
- 選択肢C：X API有料（$100/月）→ コスト合わず現実的でない

# Godot機能マップ

| カテゴリ | 機能 |
|--|--|
| 土台概念 | ノード / シーン / インスタンス化 |
| データ/イベント | Signal / カスタムResource / Autoload（ゲームの心臓） |
| UI(Control) | Container / RichTextLabel(戦闘ログ) / ProgressBar(HP) / Theme（作業量最多） |

| 判定/入力 | Area3D / RayCast3D / InputMap / カメラRaycastで選択 |
| 音 | AudioStreamPlayer / Bus |
| 2作目 | 手続き生成(RNG/FastNoiseLite) / セーブ(ResourceSaver/JSON) |
| 公開 | デスクトップビルド → itch.io / Steam |

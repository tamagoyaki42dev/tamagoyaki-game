## 運用ルール

- **大きな改修後は必ず該当セクションを実行する**
- 大きな改修（画面の書き直し・スクリプト分割等）の**前**に、私が「影響する挙動リスト」を列挙してユーザーが確認してから着手する
- 私は実装前に「影響を受ける可能性のあるテスト番号」を宣言する
- NGが出たら直してから次の機能に進む
- 新機能追加時はそのテスト項目も追記する（動作の詳細まで）

## A. 編成画面

### A-1 初期表示

**A-1-1 起動直後の表示**
- 操作: ゲームを起動する
- 期待: エラーなく編成画面が開く。コンソールにエラーが出ない

**A-1-2 キャラクターリスト**
- 操作: 起動後に左側を見る
- 期待: キャラクター一覧が表示される。各キャラに名前・職業が見える

**A-1-3 グリッド表示**
- 操作: 画面中央のグリッドを見る
- 期待: 3行×4列のマスが表示される

### A-2 キャラ配置

**A-2-1 リスト→グリッドへの配置**
- 操作: リストのキャラをグリッドのマスにドラッグ&ドロップ
- 期待: キャラがそのマスに配置される。リストから消える

**A-2-2 グリッド内移動**
- 操作: 配置済みのキャラを別のマスにドラッグ
- 期待: 移動できる。元のマスは空になる

**A-2-3 グリッドからの除外**
- 操作: 配置済みキャラをグリッド外にドラッグ
- 期待: キャラが外れてリストに戻る

**A-2-4 キャラ情報の表示**
- 操作: リスト内のキャラを確認する
- 期待: 名前・職業・ATK・SPD 等のステータスが読める

### A-3 バトル開始

**A-3-1 バトル開始ボタン**
- 操作: 1体以上グリッドに配置してバトル開始ボタンを押す
- 期待: 戦闘画面（battle.tscn）に遷移する。エラーなし

## B. 戦闘画面

### B-1 初期表示・キャラ配置

**B-1-1 画面起動**
- 操作: バトル開始後
- 期待: 3Dのアイソメトリック戦場が表示される。コンソールにエラーが出ない

**B-1-2 プレイヤーキャラの配置数・位置**
- 操作: 複数キャラを編成してバトル開始（例: 7体）
- 期待: 編成と同じ数のキャラが表示される。グリッドのマス位置に対応する位置に立っている
- NG: 全員が同一座標に重なる、数が合わない

**B-1-3 敵の配置**
- 操作: バトル画面を見る
- 期待: 敵が1体、プレイヤーと向かい合う側に表示される

**B-1-4 キャラ下のHPバー**
- 操作: 各キャラの足元を見る
- 期待: 緑の細いバーが全員に表示される（プレイヤー・敵含む）
- NG: バーが見えない、全員同じ位置に重なる

**B-1-5 右パネルの表示**
- 操作: 画面右側を見る
- 期待: キャラ名・ATK・SPDが並び、HPバーが**緑色**で表示される
- NG: バーが灰色のまま

**B-1-6 敵行動パネル**
- 操作: 画面右側の敵情報エリアを見る
- 期待: 敵の行動サイクル（例: 全体攻撃 / 力を溜める 等）がリスト表示される。現在のターンの行動に「▶」マークがある

### B-2 リアルタイム・選択フェーズ

このセクションは挙動の詳細が重要なため、操作手順を明記する。

**B-2-1 第1ターンの自動進行**
- 操作: バトル開始後、何もボタンを押さない
- 期待: プレイヤーの操作なしに第1ターンの攻撃が順番に流れる
- NG: 何かボタンを押すまで戦闘が始まらない

**B-2-2 アクション間の間隔**
- 操作: 第1ターンをよく見る
- 期待: 各ユニットの攻撃と攻撃の間に約1秒の間がある。前のキャラのアニメが見えてから次のキャラが動く
- NG: 全キャラが一瞬で動いて静止する（間隔がない）

**B-2-3 カウントダウンの開始**
- 操作: 第1ターンの全アクションが終わった後
- 期待: 画面中央付近に「3」「2」「1」のカウントダウンが表示される。「Stay...」のテキストが見える
- NG: カウントダウンが出ない、すぐ次のターンが始まる

**B-2-4 デフォルト選択の確認**
- 操作: カウントダウン開始時のボタンの見た目を確認する
- 期待: ステイボタンが明るく表示されている。ローテーションボタンは半透明で暗い。何も押さずに0になるとステイで次ターンが進む
- NG: 両ボタンが同じ明るさ、または押さないと何も起きない

**B-2-5 ローテーション選択（3秒以内）**
- 操作: カウントダウン中（「2」のあたり）でローテーションボタンを押す
- 期待:
  - ボタンを押した**瞬間には次のターンが始まらない**
  - ローテーションボタンが明るくなり、ステイボタンが暗くなる
  - 「Rotate...」のテキストに変わる
  - カウントダウンはそのまま継続する
- NG: ボタンを押した瞬間にローテーションが発動する

**B-2-6 選択の変更（ローテーション→ステイ）**
- 操作: ローテーションを選んだ後（まだカウントダウン中に）ステイボタンを押す
- 期待:
  - ステイボタンが明るくなり、「Stay...」に戻る
  - カウントダウンはまだ動いている
  - 0になったときにステイで実行される（ローテーションしない）
- NG: 二度押しで即発動する、変更できない

**B-2-7 カウントダウン終了時の実行**
- 操作: ローテーションを選択してそのまま0になるのを待つ
- 期待: カウントダウンが「0」になった瞬間に、選択していたローテーションが実行される。キャラが新しい位置へ移動してから次ターンのアクションが始まる
- NG: 0になっても何も起きない、ステイで実行される

**B-2-8 実行中のボタン状態**
- 操作: 次ターンのアクションが流れている間にボタンを確認する
- 期待: 両ボタンがグレーアウト（押せない）。ターンのアクションがすべて終わってから再び有効になる

### B-3 戦闘アニメーション

**B-3-1 攻撃アニメ（前進・戻り）**
- 操作: キャラが攻撃するのを見る
- 期待: 攻撃キャラが少し後退（予備動作）→ 前進 → 元の位置へ戻るアニメが見える
- NG: キャラが全く動かない、瞬間移動する

**B-3-2 被弾flash**
- 操作: キャラがダメージを受ける瞬間を見る
- 期待: 被弾キャラが一瞬赤くなる（約0.08秒）
- NG: flash が出ない、全員が赤くなる

**B-3-3 揺れ・ノックバック**
- 操作: 被弾時
- 期待: 少しランダムに揺れて、攻撃の向きと逆に小さくノックバック。すぐ元の位置に戻る

**B-3-4 ダメージ数字**
- 操作: 攻撃が当たった瞬間
- 期待: 被弾キャラの頭上付近に「-13」のような数字が出て、上に浮きながらフェードアウトする
- クリティカル時は金色で表示される
- NG: 数字が出ない、画面端に出る

**B-3-5 回復数字**
- 操作: 後列回復や回復行動が発動したとき
- 期待: 回復したキャラに「+8」のような緑の数字が出て上に浮きフェードアウト

**B-3-6 撃破アニメ**
- 操作: キャラのHPが0になる瞬間
- 期待: 一瞬squash（横に膨らむ）してから縮小・傾きながら消える（0.4秒）。着弾点付近にオレンジの火花パーティクルが出る

**B-3-7 ローテーションアニメ**
- 操作: ローテーション選択して実行後
- 期待: プレイヤーキャラが新しいマス位置へ滑らかにスライド移動する（約0.9秒）。移動が終わってから次ターンのアクションが始まる

### B-4 UI・ログ

**B-4-1 ターン数**
- 操作: 戦闘を数ターン進める
- 期待: 左上の「Turn N」が毎ターン更新される

**B-4-2 バトルログの流れ**
- 操作: ログエリアを見る
- 期待: 攻撃・補助・回復・石化 等がリアルタイムで追記されスクロールする

**B-4-3 右パネルのHPバー減少**
- 操作: プレイヤーキャラがダメージを受ける
- 期待: 受けたキャラのHPバーが短くなる。ダメージが大きいほど大きく減る

**B-4-4 キャラ下HPバーの減少**
- 操作: 任意のキャラがダメージを受ける
- 期待: そのキャラの足元にある緑バーが短くなる（プレイヤー・敵どちらも）

**B-4-5 補助ログ**
- 操作: 攻補・防補持ちを配置して戦闘
- 期待: 攻補は「〇〇 攻撃補助」、防補は「〇〇 守護 → △△」のようにログに色付きで出る

---

### B-5 ゲームロジック・終了

**B-5-1 勝利条件**
- 操作: 敵を倒す
- 期待: 「Victory!」テキスト表示、ログに「勝利」が出る。約2.5秒後に編成画面へ戻る

**B-5-2 撤退条件**
- 操作: 味方が1人でも撃破される
- 期待: 「Retreat...」テキスト表示。約2.5秒後に編成画面へ戻る

**B-5-3 ローテーション後の前列**
- 操作: ローテーション実行
- 期待: 前列だったキャラが中・後列へ下がり、後列が前に出る。ログに行動順が変わって表示される

**B-5-4 ステイの確認**
- 操作: ステイを選択
- 期待: キャラ位置は変わらず、同じ前列で次ターンが始まる

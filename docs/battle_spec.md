
# 戦闘システム仕様書

## 概要

マイナーセブン（モールモースの騎兵隊）のローテーションバトルをベースに、  
極振りエネミー・死の恩恵・完全情報開示を加えた戦略パズル型バトル。  
**当面の目標：既存システムの忠実な再現。独自要素は後から追加。**

---

## グリッド構造

```
      マス1  マス2  マス3  マス4
前列 [ユニット][ユニット][   ][ユニット]  ← 攻撃列（敵と直接戦う）
中列 [ユニット][ユニット][   ][ユニット]  ← 補助列（前列を支援 / 間接攻撃）
後列 [ユニット][   ][   ][ユニット]  ← 回復列（ローテーション後に回復）
```

- **3列（前/中/後）× 横4マス** = 12マス
- 空きマスがあっても戦える
- 敵は1体（当面固定）

### 初期配置

- パーティ人数：**最大7人**（12マスのうち7マスまで使用可能）
- 配置はプレイヤーが戦闘前に決める（どのユニットをどのマスに置くか自由）
- 同じ縦マスに補助・回復持ちを揃えるのが基本戦略
- **初期実装の簡易対応**：固定配置でも可（例：前列マス1〜2に攻撃職、中列マス1〜2に補助職）

---

## 各列の役割

### 前列（攻撃列）
- 毎ターン、素早さ順で前列ユニットと敵が行動する
- 中央寄りのマスほど敵に狙われやすい（マス1/4より2/3が高確率）
- ただし敵の思考によっては特定条件のユニットが優先的に狙われる

### 中列（補助列）
- **補助は自動発動**（手動操作なし）
  - 前列ユニットが攻撃するとき → 攻撃補助が自動発動
  - 敵が前列ユニットを攻撃するとき → 防御補助が自動発動
- 補助の効果は**同縦マスの前列ユニット1人**にのみ有効
- 補助能力は**1回使うとローテーションするまで再使用不可**
- 間接攻撃を持つユニットは、目前（同縦マスの前列）に誰もいない場合に自動攻撃
- 前列に誰もいない場合、**通常の2倍ダメージ**を受ける（ターゲット選択は通常の前列と同じロジック：マス2/3優先・敵の思考タイプ適用）

### 後列（回復列）
- ローテーション確定後のフェーズに、**回復能力を持つユニットのみ**発動する
- 自回復：自分のHPを回復（ローテーションなしで後列に留まっていても毎ターン発動）
- 列回復：同縦マスの他のユニットのHPを回復（自分は回復しない）
- 前列・中列に誰もいない場合、**通常の2倍ダメージ**を受ける（ターゲット選択は同上）

---

## ローテーション

- **回転順：前列 → 後列 → 中列 → 前列 → …**
  - 前列で戦ったユニットが後列に下がって回復、次に中列で補助、再び前列へ
  - 織田の鉄砲隊のイメージ

```
ローテーション前:          ローテーション後:
前列 [ A ][ B ][ C ][ D ]  → 後列へ
中列 [ E ][ F ][ G ][ H ]  → 前列へ（新アクティブ）
後列 [ I ][ J ][ K ][ L ]  → 中列へ
```

- プレイヤーの操作は「**ローテーションボタン** / **ステイボタン**」のみ
- **デフォルト：ステイ**（タイマー切れで自動ステイ確定）
- ローテーションボタンを押すと列を入れ替え
- ローテーションによって元の攻撃対象が前列からいなくなった場合、**敵は新しい前列から攻撃対象を選び直す**

---

## 1ターンの流れ

```
1. 敵の行動種類を表示（「攻撃」「力を溜める」など。攻撃対象・ダメージ量は表示しない）
2. タイマー開始（3秒）
   → タイマー切れ or ステイボタン → ステイ確定
   → ローテーションボタン → 列入れ替え確定（ここで即座に列が入れ替わる）
3. 前列ユニット・中列間接攻撃持ち・敵を合わせた素早さ順で行動
   - 素早さが同値のユニット同士：マス番号順（1→4）で処理
   - 素早さが敵と同値のユニット：ランダムで先攻を決定
   - 味方ユニットの攻撃時：同縦マスの中列から攻撃補助が自動発動（未使用の場合）
   - 敵の攻撃時：ターゲットの同縦マスの中列から防御補助が自動発動（未使用の場合）
   - 中列間接攻撃持ちは目前（同縦マス・前列）が空きの場合のみ攻撃
4. 後列の回復処理（回復能力持ちのユニットのみ発動）
5. 次のターンへ
```

### 1ターン目の特殊ルール

- 戦闘開始直後（1ターン目）は step1・step2 をスキップし、**初期配置のまま step3（戦闘）から自動開始**する
- プレイヤーへの入力要求はなく、ローテーションも発生しない
- 2ターン目以降から通常の step1〜5 の流れになる

### ローテーションのタイミング

- ローテーション（列入れ替え）は step2 で確定し、**step3（戦闘フェーズ）の前に即座に実行される**
- 戦闘は入れ替え後の列配置で行われる

## 能力値

優秀な値は赤で表示（HP30以上、補助系20以上が目安）。

| 能力値 | 説明 | 発揮される列 |
|--------|------|-------------|
| **HP** | 生命力。この値を超えるダメージを受けると強制離脱。戦闘終了後に全回復 | 全列 |
| **攻撃力** | 前列で敵に与えるダメージ | 前列 |
| **素早さ** | 前列ユニットと敵の行動順を決定する | 前列 |
| **間接攻撃力** | アーチャー・ヴァルキリーのみ。目前が空きの時、中列から自動攻撃 | 中列 |
| **攻撃補助力** | 前列の同縦マスユニットの与ダメージに加算。1回使用でローテーションまで不可 | 中列 |
| **攻撃補助力(列)** | ※独自追加。発動時に前列の攻撃が列攻撃になる。敵複数時は（補助力+攻撃力）÷敵数が各敵へのダメージ。1回使用でローテーションまで不可 | 中列 |
| **防御補助力** | 前列の同縦マスユニットの被ダメージをこの値だけ軽減。1回使用でローテーションまで不可 | 中列 |
| **回復力(自)** | 後列に留まっている間、毎ターン自分のHPを回復 | 後列 |
| **回復力(列)** | 後列で同縦マスの他ユニットのHPを回復。自分は回復しない。縦マスに自分しかいない場合は無効 | 後列 |

## ダメージ計算式

| 状況 | 計算式 |
|------|--------|
| 通常攻撃 | 攻撃力 + 攻撃補助力 |
| クリティカル | (攻撃力 + 攻撃補助力) × 1.5 |
| クリティカルチャージ | (攻撃力 + 攻撃補助力) × チャージ倍率 |
| クリティカル＋チャージ | (攻撃力 + 攻撃補助力) × 1.5 × チャージ倍率 |
| 石化中への攻撃 | (攻撃力 + 攻撃補助力) × 1.5 |
| 石化中へのクリティカル | (攻撃力 + 攻撃補助力) × 1.5(石化) × 1.5(クリティカル) |
| 石化中へのチャージ攻撃 | (攻撃力 + 攻撃補助力) × 1.5(石化) × チャージ倍率 |
| 石化中へのクリティカル＋チャージ | (攻撃力 + 攻撃補助力) × 1.5(石化) × 1.5(クリティカル) × チャージ倍率 |
| 間接攻撃（通常） | 間接攻撃力 |
| 間接攻撃（クリティカル） | 間接攻撃力 × 1.5 |
| 間接攻撃（チャージ） | 間接攻撃力 × チャージ倍率 |
| 間接攻撃（クリティカル＋チャージ） | 間接攻撃力 × 1.5 × チャージ倍率 |
| 間接攻撃（石化中） | 間接攻撃力 × 1.5 |
| 間接攻撃（石化中＋クリティカル） | 間接攻撃力 × 1.5(石化) × 1.5(クリティカル) |
| 間接攻撃（石化中＋チャージ） | 間接攻撃力 × 1.5(石化) × チャージ倍率 |
| 間接攻撃（石化中＋クリティカル＋チャージ） | 間接攻撃力 × 1.5(石化) × 1.5(クリティカル) × チャージ倍率 |

- 攻撃補助力は中列に補助持ちがいて未使用の場合のみ加算される
- 間接攻撃には攻撃補助は乗らない（中列から中列への補助は存在しないため）
- クリティカルとクリティカルチャージは重複する
- **端数は全て切り上げ**（全計算共通）

### 被ダメージ計算

| 状況 | 計算式 |
|------|--------|
| 防御補助なし | 敵の攻撃力 |
| 防御補助あり | max(0, 敵の攻撃力 − 防御補助力) |

- 防御補助でダメージが0になった場合、石化は発動しない
- ×N連続攻撃に対する防御補助は**1回のみ発動**（最初のヒットを軽減。2ヒット目以降は生のATKが当たる）

---

## クリティカル

- 攻撃時に稀に通常より大きなダメージが発生（倍率1.5倍）
- クリティカル発生率は職業によって異なる
  - **サムライ・幻術師：10%**
  - **その他の職業：5%**

---

## クリティカルチャージ

- 最大HPを超えた回復量が蓄積される
- **蓄積量が最大HPの2倍以上になると**クリティカルチャージ状態になる
  - 例：最大HP19のユニットが満タン状態で38以上の回復を受けた場合
- チャージ状態で攻撃すると与ダメージが増加
  - 倍率 = min(4.0, (最大HP + 余剰回復量) / 最大HP / 2)
  - 最小1.5倍 / 最大4倍（上限は min で強制）
- **攻撃すると消費**（蓄積0に戻る）
- ×N攻撃（巫女×4、ニンジャ×2）でチャージ発動した場合、**最初の1撃のみ**チャージ倍率が適用される
- ×N攻撃のクリティカル判定は**各ヒットが独立して**行う
- **攻撃前にダメージを受けると消滅**（前列空きで中列が被弾した場合も消滅）

---

## 石化

- 祈祷師の攻撃が命中すると対象が**石化状態**になる
- 石化中のユニットはその後の行動フェーズで**行動できない**
- 石化中のユニットが攻撃を受けると**1.5倍ダメージ**を受ける
  - 攻撃補助が乗っている場合は `(攻撃力 + 補助力) × 1.5` で計算
- ×N攻撃の途中で石化が発生した場合、**残りのN-1回の攻撃は石化中（1.5倍）として当たる**
- **解除条件**：石化攻撃を再度受ける、またはローテーション
  - 味方ユニットの石化：プレイヤーがローテーションすると解除
  - 敵の石化：プレイヤーがローテーションしても解除される（原作準拠）
  - 石化攻撃で解除された場合：そのターン中に解除された直後に行動する
- **防御補助でダメージが0になった場合は石化しない**

## 敵システム

### グリッド上の扱い

- 敵は**行/列の概念を持たない**（ローテーションなし、マス配置なし）
- 複数体が出現した場合も横並びの表示のみ（将来実装）
- 当面は1体固定

### 敵の生成
- ランダム生成だが**必ず倒せる範囲内**のステータスで生成する
- 極振り個体が一定確率で出現

| タイプ | 例 |
|--------|-----|
| 通常 | HP100 / ATK20 / SPD10 |
| 極振り（バーサーク） | HP低 / ATK高 / SPD高 |
| 極振り（スピード） | HP中 / ATK中 / SPD極高 |

### 敵の思考（ターゲット選択）
- 毎ターン開始時に**行動種類のみ開示**（攻撃対象・ダメージ量は表示しない）
- 思考の例：
  - きまぐれ：ランダム
  - HPが低い者を狙う
  - 特定の職業を狙う

## 完全情報開示

戦闘開始前・各ターン開始時に以下を全て表示：

- 敵の現在HP / 最大HP / ATK / SPD / 特殊思考
- 各ユニットのHP・クリティカルチャージ蓄積量
- 中列補助の使用可否（ローテーション前に使用済みかどうか）

※攻撃対象・ダメージ量は表示しない。敵の行動種類（「攻撃」など）のみ表示する

---

## 勝敗条件

### 勝利
- 敵のHPが0になった時点でプレイヤーの勝利

### 撤退（敗北）
- 味方ユニットが**1体でも倒れたら即撤退**
- 撤退時は「死の恩恵」が発動（世代継承システムへ）

### 強制撤退
- **ターン上限：100ターン**を超えたら強制撤退（敗北扱い・死の恩恵が発動）

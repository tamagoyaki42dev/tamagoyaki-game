
# ユニットステータス仕様書

## ステ割り当て原則

- **その職が「持つ」ステータスは0にしない。** 職のアイデンティティを成すステは正の値を与える（点数調整のために自回復等を0に削るのは禁止）。逆に職が本来持たないステ（例：戦士の補助系）は0でよい
- 調整値は総合ポイント式（後述）で検算するが、設計はフィール（職の像）優先・式は検算用

## 設計方針

- お試し実装バランス：ある程度簡単に勝てる水準
- 敵の通常攻撃（バランス型ATK8〜16）を防御補助で概ね軽減できる
- 標準的な前列2人 + 攻撃補助で、バランス敵（HP80〜200）を5〜8ターンで倒せる
- バーサーカー（ATK18〜28）も防御補助があれば耐えられる
- タンク（HP250〜450・自己回復8〜18）も100ターン以内に確実に倒せる

## 赤表示基準（再掲）

battle_spec より：HP30以上、補助系20以上が赤表示の目安。

## ステータス一覧（値はコードが正）

各職のベース値（HP / ATK / SPD / 間接ATK / 攻補 / 防補 / 自回復 / 列回復）の **single source of truth は `character_data.gd` の CHAR_BASE**。二重管理を避けるためここには数値表を持たない（値が要るときはコードを見る／grep で一覧できる）。

- ★ = 初期実装5職（戦士・騎士・神官・魔女・アーチャー）
- ATK の (石化)・(×2)・(×4) は攻撃の特殊効果。間接ATK はアーチャー・ヴァルキリーのみ
- **どの職がどのステを持つか（職の設計像）は下記「職業別メモ」が言葉で保持する**

---

## バランス検証（設計知見）

具体的な与ダメ/被ダメの数値例は旧ステ準拠で陳腐化したため削除した（値が要るときは `character_data.gd` ＋ battle_spec の計算式から算出する）。式と設計上の要点だけ残す：

- **防御補助は1撃目のみ軽減**。×N連続の総ダメージ = `max(0, ATK − 防補) + ATK × (N−1)`。2発目以降は素通り
- **バーサーカー＋乱打型は防御補助で完全には防げない**。先手で倒しきるか、前列に耐久職を置く対応が必要
- **タンク（高HP・高自己回復）には攻撃補助が実質必須**。補助なしだと正味ダメージが自己回復に食われて詰む＝補助職の価値が出るバランス設計になっている

## 職業別メモ

- **戦士**：最もシンプル。補助と組み合わせると高火力
- **騎士**：防補12は中程度だが自回復8で自立する。中列・後列向き
- **神官**：HP18は最低クラスだが防補20は最強クラス。列回復15で後列から全体支援
- **魔女**：攻補14 + 防補12の補助二刀流。速さ16で先手が取れる。回復なし
- **アーチャー**：前列でも間接でも戦える万能型。間接ATK12は補助が乗らないため単独火力
- **魔術師**：攻補20（赤）+ 列回復10。防補なし。前列ATK8は低いが中列から攻守サポート
- **サムライ**：SPD28はほぼ最速。ATK24 + クリ10%でクリティカルチャージ狙いが強力
- **ニンジャ**：ATK18×2 + クリ10%。2ヒットそれぞれがクリ判定なので会心が出やすい
- **聖騎士**：攻補22（赤）・防補18・列回復18の全部盛り。補助特化の切り札
- **巫女**：ATK6×4=24。祈祷師で石化した敵に当てると6+9×3=33。コンボ前提の設計

## 個体差

同じ職業でも個体ごとにステータスが異なる。

- 全数値ステータス（HP / ATK / SPD / 間接ATK / 攻補 / 防補 / 自回復 / 列回復）が対象
- 生成時に各ステータスを **ベース値 × 0.8〜1.2 の範囲でランダム生成**（切り上げ・最小1）
- 赤表示判定は個体の実際の値で行う（HP30以上、補助系20以上）

例：神官（ベース防補20）→ 個体値は 16〜24 の範囲でばらつく

## キャラ総合ポイント重みテーブル（暫定・proto1用）

**用途**：敵生成難易度設計・proto2以降の無限モードマッチメイク基礎。  
**注意**：proto2で大幅調整予定。現値は構造の骨格として使う暫定値。

### 重み一覧

| ステータス | 重み | 設計根拠 |
|---|---|---|
| HP | **1.5** | 高 / 生存に直結。全列で有効 |
| ATK | **1.5** | 高 / ダメージ効率に直結 |
| 防補 | **1.5** | 高 / 複数ターンに渡る被ダメ軽減 |
| 攻補 | **1.2** | 中高 / 使用回数制限あり（ローテーションでリセット） |
| 間接ATK | **1.0** | 中 / 発動は条件付き（同縦前列が空のときのみ） |
| 自回復 | **1.0** | 中 / 後列時のみ・自分のみだが、毎ターン継続回復のため長期戦では一回バフのHPより効く（連撃と同様、フラットな低重みが過小評価だったため0.8→1.0に修正） |
| 列回復 | **0.7** | 中 / 単体評価は低いが編成全体で高価値。個人評価として0.7、編成判断時は合算で見る |
| SPD | **0.3** | 低 / 先手効果はあるが単独では貢献小 |

**総合ポイント = Σ(各ステータス × 重み) + 特殊補正の合計**

### 特殊補正

| 特性 | 計算式 | 理由 |
|---|---|---|
| ×N連続攻撃 | `ATK × (N-1) × 1.5` を加算 | 敵の防御は初回ヒット1発のみ軽減し2発目以降は素通り（盾＝`shield_active`・battle_manager.gd）。よって追加ヒットはフルダメージ＝ATK重み1.5で評価する。さらに「1発の攻撃 ＜ 敵防御」のときは床0で潰される1発目の無駄が減り素通り分が残る＝条件付き貫通利得（巫女など低火力多段で発生）は"数えない上振れ"として残す |
| 石化攻撃 | `+8` フラット | 行動阻害＋被ダメ1.5倍の戦略価値 |
| クリ率 | `ATK × crit_rate × 0.5 × N` を加算 | クリ期待値。連撃は各ヒットが独立に会心判定するためヒット数Nを掛ける |

## ステータス上限・下限（設計ガードレール・2026-07-04）

**用途**：新職追加・既存職調整のときに「この範囲を超えたらバランスが壊れる」を判定する床/天井。単なる現行値の最小最大ではなく、各値ごとに壊れる具体シナリオから逆算した。現行17職（proto1の15職＋上級職2＝魔騎士・聖騎士）は全ステータスがこの範囲内に収まる。

| ステータス | 下限 | 上限 | 根拠 |
|---|---|---|---|
| HP | 16 | 50 | 下限＝標準バランス敵の通常攻撃上限（ATK16）を素で1発受けても離脱しない床（`battle_spec.md`「HPを超えるダメージで強制離脱」＝ダメージ＝HPは離脱しない境界のため16が床）。上限＝バーサーカーの会心ダメージ（28×1.5=42）を素でも常時耐えるようになると、防御補助・回復列（被ダメを軽減する/戻す）の存在価値が薄れる |
| ATK | 6 | 28 | 下限＝敵の初回防御（`initial_defense` 最大10・B3）を上回れず「攻撃しても素通り」になる床（巫女はATK6だが×4=24相当のため実質圏外）。上限＝敵最強格（バーサーカーATK上限28）と同格まで。これを超えると標準敵（HP80〜200）を2ターンで単独撃破できてしまい、5〜8ターンで倒すテンポ設計と他職の出番が崩れる |
| SPD | 3 | 34 | 下限＝行動順が常に最後固定でも数値比較自体は壊れない実務下限（0付近だと同値判定・石化解除順のバグ温床）。上限＝敵最速（スピードスター上限35）未満に必ず留める。35以上にすると「どんな敵より必ず先に動く」が確定し、先手を取れないリスクという緊張感自体が消える |
| 間接ATK | 8 | 26 | 下限＝前列最低クラスのATK相当を下回ると中列に置く意味がない。上限＝前列ATK上限（28）を下回る範囲に留める。同格以上にすると被弾リスクゼロの中列から前列と同じ火力が出せてしまい、「リスクを取らない代わりに低め」という間接攻撃職のトレードオフが崩れる |
| 攻補 | 6 | 24 | 下限＝この値未満だと敵の初回防御（最大10）を剥がしきれず"焼け石に水"になる。上限＝乗せた瞬間に前列アタッカー間のATK差（6〜28）を圧縮し尽くし、誰が前に出ても同じ火力になるdominanceを生む |
| 防補 | 6 | 22 | 下限＝標準バランス敵の最低ATK（8）の大部分（6/8＝75%）を軽減できるライン。これ未満だと軽減が誤差になる（完全無力化ではなく"手応えを大きく削る"のが床の基準）。上限＝強化バランス上限（ATK22）まで完全無力化できるようになると、耐久がHP・自回復でなく防御補助だけで完結し、耐久設計の他要素が形骸化する |
| 自回復 | 5 | 18 | 下限＝ローテ周期（3ターンで1回帰還）を踏まえた実効回復量が個体差-20%でも意味を持つ床。上限＝敵タンクの自己回復上限（18）と同格まで。これを超えると後列に置くだけで実質不死になり、「前列で受けて後列で治す」役割分担自体が要らなくなる |
| 列回復 | 8 | 20 | 下限＝敵の最低ATK（6）を1人分軽減できるライン未満だと"打たれ負け"が確定する。上限＝後列に1人置くだけで編成全体のHPが毎ターン20回復し、タンク敵との我慢比べ（100ターン以内に倒す）という制約が崩れる |

**注意**：この表は「単発の職業設計が壊れる境界」であり、複数職の組み合わせ（攻補＋防補二刀流など）まで含めた編成全体のdominanceは別途 全職スコア表 で検算する。

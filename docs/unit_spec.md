
# ユニットステータス仕様書

## ステ割り当て原則

- **その職が「持つ」ステータスは0にしない。** 職のアイデンティティを成すステは正の値を与える（点数調整のために自回復等を0に削るのは禁止）。逆に職が本来持たないステ（例：戦士の補助系）は0でよい
- 調整値は総合ポイント式（後述）で検算するが、設計はフィール（職の像）優先・式は検算用

## 設計方針

- お試し実装バランス：ある程度簡単に勝てる水準
- 敵の通常攻撃（バランス型ATK8〜16）を防御補助で概ね軽減できる
- 標準的な前列2人 + 攻撃補助で、バランス敵（HP80〜200）を5〜8ターンで倒せる
- バーサーカー（ATK18〜28）も防御補助があれば耐えられる
- タンク（HP250〜450・自己回復8〜18）も100ターン以内に確実に倒せる

## 赤表示基準（再掲）

battle_spec より：HP30以上、補助系20以上が赤表示の目安。

## バランス検証

> ⚠️ **2026-07-01 注記**：以下の与ダメ/被ダメ計算例はリバランス前の旧ステ（戦士ATK20 等）に基づく。新ステ（戦士ATK13 等）＋敵再調整での再計算は別タスク（敵スタット確定後にまとめて更新）。現状は計算手順の参考としてのみ有効。

### 攻撃面（与ダメージ）

| 想定編成 | 1ターンのダメージ | バランス敵HP200を倒すのに必要なターン |
|---------|----------------|----------------------------------|
| 戦士のみ | 20 | 10ターン |
| 戦士 + 魔女攻補（同縦） | 34 | 6ターン |
| アーチャー間接（目前空き） | 12 | 17ターン |
| 剣闘士 + 剣闘士攻補（同縦） | 34 | 6ターン |

### 防御面（被ダメージ軽減）

| 敵ATK | 防補なし | 騎士防補12 | 神官防補20 |
|-------|---------|-----------|-----------|
| バランス最大 16 | 16 | 4 | 0 |
| バーサーカー平均 23 | 23 | 11 | 3 |
| バーサーカー最大 28 | 28 | 16 | 8 |

神官防補20があればほぼどの敵の通常攻撃も軽減できる。

### ×N連続攻撃への防御（バーサーカー想定）

防御補助は1回のみ発動（最初のヒットを軽減、2ヒット目以降は生ATK）。  
総ダメージ = max(0, ATK − 防補) + ATK × (N−1)

| 敵ATK | ×2連続・防補なし | ×2連続・騎士防補12 | ×2連続・神官防補20 |
|-------|----------------|-------------------|-------------------|
| 平均 23 | 46 | 34 | 26 |
| 最大 28 | 56 | 44 | 36 |

神官防補20でも×2連続最大28ATKで36ダメ → 神官HP18は即死。  
**バーサーカー + 乱打型は防補で完全には防げない。先手で倒しきるか、前列に耐久職を置く対応が必要。**

### タンク戦の最悪ケース確認

- タンク最大値：HP450・ATK12・自己回復18
- 戦士ATK20（補助なし）- 自己回復18 = 正味2ダメ/ターン → 225ターン必要 → **詰む**
- 戦士 + 魔女攻補14 = 34 - 自己回復18 = 正味16ダメ/ターン → 28ターン → **問題なし**

→ タンクには攻撃補助が実質必須。補助職の価値が出るバランス設計になっている。

## 職業別メモ

- **戦士**：最もシンプル。補助と組み合わせると高火力
- **騎士**：防補12は中程度だが自回復8で自立する。中列・後列向き
- **神官**：HP18は最低クラスだが防補20は最強クラス。列回復15で後列から全体支援
- **魔女**：攻補14 + 防補12の補助二刀流。速さ16で先手が取れる。回復なし
- **アーチャー**：前列でも間接でも戦える万能型。間接ATK12は補助が乗らないため単独火力
- **魔術師**：攻補20（赤）+ 列回復10。防補なし。前列ATK8は低いが中列から攻守サポート
- **サムライ**：SPD28はほぼ最速。ATK24 + クリ10%でクリティカルチャージ狙いが強力
- **ニンジャ**：ATK18×2 + クリ10%。2ヒットそれぞれがクリ判定なので会心が出やすい
- **聖騎士**：攻補22（赤）・防補18・列回復18の全部盛り。補助特化の切り札
- **巫女**：ATK6×4=24。祈祷師で石化した敵に当てると6+9×3=33。コンボ前提の設計

## 個体差

同じ職業でも個体ごとにステータスが異なる。

- 全数値ステータス（HP / ATK / SPD / 間接ATK / 攻補 / 防補 / 自回復 / 列回復）が対象
- 生成時に各ステータスを **ベース値 × 0.8〜1.2 の範囲でランダム生成**（切り上げ・最小1）
- 赤表示判定は個体の実際の値で行う（HP30以上、補助系20以上）

例：神官（ベース防補20）→ 個体値は 16〜24 の範囲でばらつく

## キャラ総合ポイント重みテーブル（暫定・proto1用）

**用途**：敵生成難易度設計・proto2以降の無限モードマッチメイク基礎。  
**注意**：proto2で大幅調整予定。現値は構造の骨格として使う暫定値。

### 重み一覧

| ステータス | 重み | 設計根拠 |
|---|---|---|
| HP | **1.5** | 高 / 生存に直結。全列で有効 |
| ATK | **1.5** | 高 / ダメージ効率に直結 |
| 防補 | **1.5** | 高 / 複数ターンに渡る被ダメ軽減 |
| 攻補 | **1.2** | 中高 / 使用回数制限あり（ローテーションでリセット） |
| 間接ATK | **1.0** | 中 / 発動は条件付き（同縦前列が空のときのみ） |
| 自回復 | **1.0** | 中 / 後列時のみ・自分のみだが、毎ターン継続回復のため長期戦では一回バフのHPより効く（連撃と同様、フラットな低重みが過小評価だったため0.8→1.0に修正） |
| 列回復 | **0.7** | 中 / 単体評価は低いが編成全体で高価値。個人評価として0.7、編成判断時は合算で見る |
| SPD | **0.3** | 低 / 先手効果はあるが単独では貢献小 |

**総合ポイント = Σ(各ステータス × 重み) + 特殊補正の合計**

### 特殊補正

| 特性 | 計算式 | 理由 |
|---|---|---|
| ×N連続攻撃 | `ATK × (N-1) × 1.5` を加算 | 敵の防御は初回ヒット1発のみ軽減し2発目以降は素通り（盾＝`shield_active`・battle_manager.gd）。よって追加ヒットはフルダメージ＝ATK重み1.5で評価する。さらに「1発の攻撃 ＜ 敵防御」のときは床0で潰される1発目の無駄が減り素通り分が残る＝条件付き貫通利得（巫女など低火力多段で発生）は"数えない上振れ"として残す |
| 石化攻撃 | `+8` フラット | 行動阻害＋被ダメ1.5倍の戦略価値 |
| クリ率 | `ATK × crit_rate × 0.5 × N` を加算 | クリ期待値。連撃は各ヒットが独立に会心判定するためヒット数Nを掛ける |

## 何を作るか（2026-07-19 の会話で確定）

煙の尾を持つ空気の巨人。**思い切り右ストレートを打つアニメーション**を作るのが目的で、
モデルはそのための土台。

- ずんぐりした寸胴、**極端に太い腕**、丸い腹
- **脚と足は無い**。腰から下は螺旋状の煙の尾で接地
- 頭は横に広く、**単純な円錐の角が2本**
- 顔は大幅に簡略化してよい（**平らな点の目・横に広い口**。くぼんだ眼窩は作らない）
- 単色。服は無い

## なぜこの題材が自作に向くか

7/18に自作ドラゴンを打ち切った理由（**眼窩・角と頭の色境界・翼膜**）が、この設計では
3つとも発生しない。眼窩が無く、単色で境界が無く、膜が無い。
さらに脚・足・服も無い。残るのは丸い塊・太い先細り・円錐の角＝手続き生成で安い形だけ。

**私にとって安い複雑さ**＝パーツ数・手足の本数・左右非対称・角やトゲ・色数
**私にとって高い複雑さ**＝連続的な有機面（膜・筋肉の移行）・凹んだ形（眼窩・入れ子）・
テクスチャで描く模様

## 進め方（2段階・各段でユーザーが判定してから次へ）

1. **全身ブロックアウト** → 6方向を1枚にして参考画像と並べて提示 → 形の判定
2. **リグ＋パンチ** → ハーネスで数値検証してから提示 → 動きの判定

## モーション方針

**Mixamoの自動リグは使わない**（脚が無いモデルでは関節推定に失敗する）。
パンチのクリップだけ落として、**リグはこちらで `mixamorig:` 命名に合わせて組み**、
名前で合流して**上半身のトラックだけ使う**（腰・脚のトラックは捨てる）。尾は別のボーン列。
合流後は必ず `tools/diag_harness_control.gd` で骨の長さと辺の破綻を測ってから目視判定する
（CLAUDE.md「測定と検証の規律」）。

## 既知の懸念

- **煙の尾**だけが「なめらかで連続した有機面」＝高い側。半透明にしたい場合、
  クレイシェーダーはalbedoしか読まないため透過が落ちる。不透明の螺旋リボンで成立するかは要目視
- **パンチ時の肩と脇**が潰れないか。ルート採用の成否を決める本命リスク
- 参考画像にある**胸筋・腹筋の彫り込みはローポリでは落ちる**（シルエットは保てる）

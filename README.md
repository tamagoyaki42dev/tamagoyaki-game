# たまごやきゲームズ — ローテーションハクスラ

> 完全開示（オープン開発）スタイルで作るインディーゲーム。コードも進捗も全部公開。

## ゲームについて

モールモースの騎兵隊 / ヴィーナス＆ブレイブス にインスパイアされた、  
**ローテーションバトル × 世代継承 × 闘技場ハクスラ**。

### コアコンセプト

- **完全情報開示**：戦闘前に敵のタイムラインをすべて開示（詰将棋スタイル）
- **世代継承**：キャラは老い、死ぬ。その能力は次世代に受け継がれる
- **極振りエネミー**：HP5・攻撃力999みたいな理不尽な奴が突発的に出る
- **死の恩恵**：死んでも強くなる。ロードしたくなくなる設計
- **引き算の美学**：マップなし・属性なし・アニメなし。戦闘だけ磨く

### プレイ環境

- PC（ブラウザ / HTML5）
- スマホ（縦画面・タップ操作）

## 技術スタック

- **エンジン**: Godot 4 (GDScript)
- **データ**: SQLite（完全オフライン）
- **ツール**: Python
- **公開**: itch.io (HTML5)

# たまごやきゲームズ — ローテーションバトル

> 完全開示（オープン開発）スタイルで作るインディーゲーム。コードも進捗も全部公開。

## ゲームについて

モールモースの騎兵隊 / ヴィーナス＆ブレイブス にインスパイアされた、  
**ローテーションバトル × 世代継承 × 拠点整備**。

### コアコンセプト

- **面白い戦闘** — 原作（モールモース/V&B）のローテーションバトルを核とする
- **投資が形になる** — 時間をかけたものが強さになり蓄積する。世代継承でキャラへの愛着も積み上がる
- **整理整頓・工場化** — 素材加工・自動化のループ。戦闘報酬で拠点を整備し、部隊を強化するサイクル
- **引き算の美学** — マップなし・属性なし。画面遷移は拠点・編成・戦闘の3つだけ

### プレイ環境

- PC（デスクトップ）横画面

## 現在の状態

プロトタイプ1制作中。敵情報画面 → 編成 → 戦闘 → 3戦クリアまでの基本ループが動いています。

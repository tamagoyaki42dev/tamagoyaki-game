## 右パーティパネルのステータス表示を修正・再レイアウト

### 不具合：7人時にステータスがHPしか出ない
- 前回（06-25）未コミットだった「攻ライン・速・持ちステータス表示」が、パーティ7人時に **HPバーまでしか見えていなかった**。
- 原因：エントリ高さは約81px（`slot_h = 画面高×LOG_SPLIT / 人数 − 4`）。`entry.clip_contents = true` のため超過分が切り捨てられ、
  - 攻ライン（旧 y=78）はクリップで消滅
  - 速・持ちステータスは `slot_h >= 95` が表示条件だが実 slot_h は約85px で常に非表示
- GUTが緑だったのは、テストが1人パネル（slot_h=594で全部入る）とヘルパー文字列だけ見ていて、7人の見切れを検出できていなかったため。

### 修正
- ステータス（攻/速/持ち）を1本に統合し **HP数値の右に横並び**へ。バーの縦帯から外す。
  - 当初バー直下に置いたら、`ProgressBar` の最小描画高さ（size.y=5指定でも約19px）にステータスが被ったため、HP行の右へ移動して解決。
- **職種を名前行の右へ移動**（名前幅をフォントから実測し2スペースぶんの間隔で続ける）。浮いた1行ぶんでフォント拡大：名前16 / HP13 / ステータス12。漢字の可読性を改善。
- レイアウト値を const 化（`HP_ROW_Y` / `BAR_Y` / `STAT_X_OFFSET` / 各 FONT_SIZE）。

### テスト
- `tests/test_battle_ui_stat_display.gd` に回帰テスト追加：
  - 7人パネルで攻ラインがクリップ境界内に収まる
  - ステータスがHPと同じ行・右側・バーより上（バー被りの回帰防止）
  - 速・持ちステータスが統合表示に含まれる
- GUT 全 136 Pass。

## 識別UI Phase 3：行ホバー → 戦場リング強調

### 実装
- **BattleUI** に `signal unit_row_hovered(unit, hovered)` を追加。各行 Panel の `mouse_entered`/`mouse_exited`（Control 標準シグナル・3Dピッキング不要）で発火し、行背景を明滅（`ENTRY_BG_COLOR`⇄`ENTRY_BG_HOVER`）。
  - 子コントロール（ポートレート／ラベル／HPバー）を `MOUSE_FILTER_IGNORE` にして、行全体を安定したホバー対象にした（子が mouse を奪うと親 Panel の enter/exit が不安定になるため）。
- **BattleScene** が `setup()` 後に `unit_row_hovered` を購読。`_on_row_hovered` で対応する `_unit_rings[unit]` の材質を白側へ lerp ＋ emission 発光、退出で基準色へ復帰。
  - リング基準色は `_ring_base_colors` に保存。強調量は `ring_hover_brighten`(0.5) / `ring_hover_emission_energy`(2.0) の `@export`。
- 番号バッジ色＝リング色＝パネル左帯色が一致しているので「どの行＝どの戦場ユニット」が一目で分かる。

### テスト
- `tests/test_battle_ui_row_hover.gd`：発火パラメータ、行背景明滅の復帰、子の mouse IGNORE。
- `tests/test_battle_scene_ring_hover.gd`：ホバーで albedo 変化＋emission 有効、退出で復帰、未登録ユニットでも no-op。
  - BattleScene は `_ready` で @onready ノードに触れるため、ツリーに add_child せず `new()` だけで `_on_row_hovered` を検証。
- GUT 全 143 Pass（Asserts 310）。`assert_signal_emitted_with_parameters` が Object 引数比較で engine エラーを出したため、`assert_signal_emitted` ＋ `get_signal_parameters` の手動検証に切り替えた。
- ⚠ 実際のマウス移動でのホバー発火はヘッドレス自動検証外 → 実機目視で確認済み（行ホバーでリング発光・行背景明滅、退出で復帰）。

## 識別UI Phase 4：戦場ホバー → パネル行ハイライト

### 実装
- **BattleScene** に `signal unit_3d_hovered(unit, hovered)` を追加。プレイヤーキャラスポーン時に `Area3D + CapsuleShape3D` をアタッチ（`_spawn_hover_area`）。`Viewport.physics_object_picking = true` を `_setup_world()` で設定。
- **BattleUI** に `_on_unit_3d_hovered` を追加。行背景を `ENTRY_BG_HOVER` に切替（`unit_row_hovered` は emit しない。3D→パネルは一方向）。
- **BattleUI ルート Control** を `MOUSE_FILTER_IGNORE` に変更。FULL_RECT + STOP だと左側（3D 戦場）へのマウスイベントを 2D UI が先に食べるため。右パネル側は子 Panel（デフォルト STOP）が個別に処理。
- **イソメトリック視差対策**：Area3D 中心を y=0.75（体中央）から y=0.15（地面すれすれ・リング位置）に変更。高さが大きいと前列の判定が後列のスクリーン座標と重なる問題を解消。

### テスト
- `tests/test_battle_scene_3d_hover.gd`：`_on_unit_area_entered/exited` で `unit_3d_hovered` が発火、export デフォルト値が正。
- `tests/test_battle_ui_3d_hover.gd`：行背景明滅・未登録 noop・`unit_row_hovered` を emit しない。
- GUT 全 150 Pass（Asserts 324）。

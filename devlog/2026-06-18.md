## 補助演出の順番再生を実装（battle_manager.gd 全面 async 化）

`scripts/battle/battle_manager.gd` を更新：

- **SUPPORT_DELAY = 1.0s** を定数追加（ACTION_DELAY・ROTATE_DELAY と並列管理）
- 補助発動 → 攻撃&被弾 の順で演出が流れるよう、以下の関数を全て async 化してawaitを追加：
  - `_do_single_hit`: `defense_support_used.emit` 後に `await SUPPORT_DELAY`
  - `_do_hits`: `await _do_single_hit()`
  - `_execute_player_action`: `attack_support_used.emit` 後に `await SUPPORT_DELAY`、`await _do_hits()`
  - `_execute_enemy_action`: `await _do_hits()` / `await _do_single_hit()`
  - `_do_unit_action` / `advance_turn`: `await _do_unit_action()`
- 補助なし行動は従来通り ACTION_DELAY 1秒のみ

## バグ修正：3D HPバーが視覚的に更新されていない

**原因の特定と修正（2段階）**：

1. 最初の修正: `fg.scale.x = pct` は中心基点スケールで両側が均等に縮むため変化が見えにくい → `fg.position.x` で左端固定補正を追加
2. 2次バグ発覚: プレイヤーキャラは `rotation_degrees.y = 180°` で配置されているため、position.x のローカル -X がワールド +X に反転。HPが減るほどバーが逆方向にずれ、背景バー（常に全幅）だけが見えて「変化なし」に見えていた

**最終修正**: フォアグラウンドバーを ShaderMaterial に変更し、`UV.x > health_pct` の部分を `discard` するシェーダーで右から削る表示を実装。`render_mode billboard` により親ノードの回転に一切依存しない。

```
# _hp_bars に格納するものを MeshInstance3D → ShaderMaterial に変更
# _update_hp_bar が mat.set_shader_parameter("health_pct", pct) を呼ぶだけになった
```

## 敵アセット刷新の調査（$60バンドル検討→「塗られたalbedo」を買う話だと判明）

昨日（2026-07-16）の結論「**近づけ方の効く順＝アセット（塗り）＞光・材質・グレード＞ポスト＞レンダラ**」「**Kuwaharaはフラット塗りに効かない＝天井はレンダラでなくアセット**」を受けて、ユーザーが Fab の **RPG Monster Wave Bundle PBR**（Dungeon Mason・$59.99・30体）を検討。そこから敵アセットの選択肢を洗う調査を実施。

### 技術的発見：Quaternius のアトラスはテクスチャではなくカラーパレット

`assets/quaternius-ultimate-monsters/Atlas_Monsters.png` を実際に開いて判明。**1行＝1体分で、その行に並ぶ2〜9個のベタ塗り四角がそのモンスターの使用色の全部**。同梱の `Color Guide.png` に行→モンスター名の対応が載っている（Mushnub=6色、Dragon=5色など）。

**＝Quaternius のモデルには UV 展開が存在しない。** UV は「パレットのどの四角を引くか」を指しているだけで、胴体まるごとが1個の色見本を指す。

ここから確定した制約：

- **塗りを描き込む場所が物理的に無い。** アトラスに絵を描いても「その四角の色が変わる」だけ＝`recolor_part`／ティントと等価。
- **よって塗りを足す手段はシェーダー側で後から被せる一択。** フェーズ2-1の手続きノイズは選んだ手法ではなく**唯一残っていた手**だった。
- **手続きノイズの天井もここで決まる＝ムラは足せるが塗りは足せない。** 形に沿った筆致・凹みの陰・意図した位置の描き込みは出せない（ノイズは形を知らない）。
- 埋めるなら50体をBlenderでUV再展開→その上で描く、になり非現実的（かつ再展開の先に「描く」が残る）。

**＝昨日の「天井はアセット」の物理的な正体がこれ。** B（絵具）の伸びしろは、Quaternius を使い続ける限りシェーダー側のノイズで頭打ちになる。

### 探し方の語彙が間違っていた

**「ローポリ」で探すとフラットパレットしか出てこない**（Kenney / Quaternius / KayKit / Synty が全部この方式＝安く作れるから無料で配れる）。塗られた albedo を持つアセットは業界的に **「hand painted」「stylized」** という別カテゴリ。ここを軸に探し直して選択肢が一気に開いた。

### ライセンス調査結果

- **Fab Standard License はエンジン非依存**（Epic公式ブログ「any game engine or tool you want」）。tier＝過去12ヶ月の粗収益 10万ドル未満で Personal。クレジット不要。Unity Asset Store 経由だと EULA が Unity 前提でグレーになるため、**同じ物を買うなら Fab 経由が安全**。例外は Epic 自社製（Paragon/MetaHuman/Megascans）のみ。
- **Meshtint 独自EULA**：商用可・「in broadcast, multimedia, video games or animation」・再配布禁止（**コンパイル済みゲームは例外**＝出荷OK）・クレジット不要・NFT/AI学習は禁止。**エンジン制限は法的には無い**。ただし返金ポリシーに「The assets do not function in applications or game engines other than Unity」＝Unity以外で動かなくても返金しない、というサポート免責がある（法的制約ではないがリスクとして実在）。**Meshtint は Fab にも出店している**ので、Fab 経由で買えば Fab Standard License が適用されこの曖昧さ自体が消える。

### 次の判定（0円で決着する）

前日（2026-07-16）に決めた英語ハッシュタグ統一（`#gamedev #indiedev #godotengine #madewithgodot #AIgamedev`）の初回運用で、**英語圏デベロッパーから実質コメント2件**（うち1人はブラジルの開発者 @WeVennStudios、もう1人は @ericnofsinger）。どちらも「敵キャラ選定の決め手の軸は？」「デザインの前にキャラの個性とストーリーを考えろ」と**投稿の中身を読んだ上の返信**＝タグ検索→翻訳→反応の経路が実際に通っている。

**インプレッションは日本語タグ時の約1/3に低下。** ただしこれは想定内のコストと判定：英語タグはXのアルゴリズムのリーチには効かず（リーチはフォロワーグラフ＋初速エンゲージが決める）、効くのは英語gamedevコミュニティの人力タグ検索。よって「浅く広い日本語圏の通行人」が消えて「狭く濃い英語圏の同業者」が来た＝母数が減って濃度が上がった形。公開先が itch/Steam＝英語圏が本命市場なので濃度を採る。**見る数字をインプレからフォロー増・リプライ数に変える**。`docs/sns_workflow.md` に反映済み。

なお **Eric Nofsinger 氏の助言（敵の選定より先にキャラの個性・活躍のさせ方を考えろ）は、この日の敵アセット調査が長引いている状況に外から刺さった格好**。ユーザーは公開返信で「早めに切り上げてコアシステムに触れる」と表明している。
